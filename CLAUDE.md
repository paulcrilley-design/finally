# FinAlly Project - the Finance Ally

All project documentation is in the `planning` directory.

The key document is `planning/PLAN.md` (read it when planning or building a new feature, not for small fixes). The platform is built: market data, database, API, LLM chat, frontend, Docker and E2E tests. `planning/CONTRACTS.md` holds the API, data layer and test selector contracts; `planning/MARKET_DATA_SUMMARY.md` covers market data, with more detail in `planning/archive`. Consult these docs only when required. Run commands are in `README.md`. The Massive (real data) path has never run against the live service.

All UI work must follow the openUI format standard in `planning/OUI_FORMAT.md` (logo, colours, fonts, components). Design foundation files already exist under `frontend/src/` and must be preserved and reused.
