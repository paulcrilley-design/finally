# FinAlly Project - the Finance Ally

All project documentation is in the `planning` directory.

The key document is `planning/PLAN.md` (read it when planning or building a new feature, not for small fixes); the market data component has been completed and is summarized in the file `planning/MARKET_DATA_SUMMARY.md` with more details in the `planning/archive` folder. Consult these docs only when required. The remainder of the platform is still to be developed.

All UI work must follow the openUI format standard in `planning/OUI_FORMAT.md` (logo, colours, fonts, components). Design foundation files already exist under `frontend/src/` and must be preserved and reused.
